# Codex Keyboard

Codex Keyboard 把 EasyInput V2 键盘和一台 Mac 放在同一个 Wi-Fi 里。上排四个键按住说话，松开后由 Mac 转成文字，交给对应的任务。下排四个键打开对应槽的消息。键盘和 Mac 之间不经过手机页面、公网中继或远程桥。

- `S1-S4`：按住说话。Mac Host 用北京区 `qwen3-asr-flash` 转写，再按任务排队送进 Codex、Grok、Claude 或 DeepSeek。
- `S5-S8`：打开对应槽。完成时键盘已经说过「任务N已完成」，这里不再出声。新的一次按下会把这句标成听完。
- 旋钮：逆时针降低板载扬声器音量，顺时针提高。短按播放当前音量，长按 3 秒进入配置。
- 灯：左起四盏表示槽 1-4 还有没听的完成播报。最右一盏在没有故障时表示正在运行的任务数，0 到 4 依次是绿、黄、橙、紫、红。没连上 Wi-Fi、连不上 Host，或北京区密钥缺失、被拒绝、连不上时，只让这一盏闪红。

完成后不再写一段口播总结。页面和键盘都只说「任务一已完成」「任务二已完成」「任务三已完成」「任务四已完成」。这四句已经放在键盘里。回复原文留在阅读页。

## 目录

- `app/host/`：Mac 上的常驻服务，负责任务绑定、排队、完成观察和局域网音频。
- `app/desktop/`：Tauri 管理窗口。状态以 Host 为准。
- `firmware/`：ESP32-S3 固件。只认槽位，不保存任务编号。
- `docs/总体方案.md`：产品边界。
- `docs/端到端架构.md`：语音进去、结果回来的路径。
- `docs/协议草案.md`：局域网音频协议。
- `flow/`：计划、决策和当前进展。

## 本地检查

```bash
./scripts/eval-fast.sh
```

密钥放在 `~/Library/Application Support/EasyCodexInput/` 的私有文件里，权限 `0600`。仓库里不放 key、任务编号、说话内容、录音或 Wi-Fi 密码。
