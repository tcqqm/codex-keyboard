- [x] 优化 Spark 播报文本：最新结果放在最前，压缩仍相关的旧未听内容，只在确有行动时以下一步收尾；只改 prompt，不新增正文硬编码。

- [x] 桌面主界面改成阅读页，不做成聊天框。四槽在左侧；右侧正文是回复，最新一条在最上面，更早的回复默认折起。绑定和新建只出现在未绑定的空状态，或点「更换任务」后的小面板。版本、PID 和语音模型收进「设备」。
- [x] 总结播报音色改为北京区 `qwen-audio-3.0-tts-flash` 的龙川叔 `longchuanshu_v3.6`。播报指令不再指定女声。旋钮预置音量提示仍是龙安风悦，本次不烧录。

- [x] 新回复先于键盘灯出现。左侧槽位和这篇回复标出「新回复」，打开窗口时已经在的回复不算。换到别的槽后，看过的标记清掉。未听总结的绿灯不变。
- [x] 按下 S5–S8 后，把 Codex Keyboard 窗口叫到前面，并打开对应槽的消息。窗口最小化或没开着时也拉起来。播放和未听总结的原有规则不变。

- [x] 第 5 颗灯在 Grok、Claude、DeepSeek 作业排队或执行时也计入运行数。1 个为黄，和 Codex 的 `task_started` 到 `task_complete` 一起数，同一任务只计一次。固件不改。
- [x] 四个槽的总结和语音同时生成。同一任务仍一次只做一份；未听内容仍滚进下一份，新 generation 仍等完整发布后才替换。语音生成本身不计入第 5 颗灯。固件和桌面不改。
- [x] 口播稿仍调用 `gpt-5.6-luna`，reasoning effort 从 `high` 降到 `low`。四槽对话模型、音色、TTS 和固件不改。
- [x] 口播稿改走 DeepSeek 非推理模型 `deepseek-flash`，并显式关闭思考。四槽对话模型不变，槽位上的 DeepSeek 回复仍是 `deepseek-v4-pro`。音色、TTS 和固件不改。
- [x] 完成通知不再做口播总结。页面标「任务一已完成」「任务二已完成」「任务三已完成」「任务四已完成」，回复原文留在阅读页。

- [x] S5–S8 只打开对应槽，不再播放「任务N已完成」。按下已认证的新播放键后灭灯。重放、取消、断线和超时不能把这句话标成听完。

- [x] 四槽未听灯亮度已改并编出候选：coverage 1 与最右空闲绿灯同亮，之后到 16 逐级增亮。Codex、Grok、Claude、DeepSeek 共用这四颗灯；第 5 颗灯仍只数 Codex 运行任务。主机测试和 ESP-IDF v5.5.5、esp32s3、16 MB 构建已通过。

- [x] 真机确认：完成后马上说出「任务N已完成」并点亮对应槽。按 S5–S8 打开对应槽，不再出声，灯灭。空闲时第 5 颗灯为绿色。
- [ ] 最右第 5 颗灯在没连上 Wi-Fi、连不上 Host，或北京区密钥缺失、被拒绝、连不上时闪红。没有这些故障时仍按 0–4 个运行任务显示绿/黄/橙/紫/红。闪红只盖住最右这一颗，左起四颗仍表示未听。Wi-Fi 断开留 8 秒，Host 静默留 12 秒，避免入网和心跳间隙误闪。EIMB v3 用字节 7 的 0 或 1 携带北京区故障，健康包仍与旧 golden 相同。候选镜像先构建，得到精确 SHA 授权后再烧录，并在烧录后升级 Host。

## 阶段合同

每阶段必须依次完成：实现 -> 自动化 -> live/HIL（如适用）-> 提交 -> 推送。当前按用户要求不启动子智能体或额外独立审查。
